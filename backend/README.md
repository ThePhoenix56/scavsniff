# ScavSniff - Backend

## Description
This is the backend for the ScavSniff project. It is a web application that allows users to search, filter and get notified about the best deals on Blocket and other marketplaces.

## Installation
To run this project, you need to have NodeJS installed. Then, run the following commands:
```bash
npm install
```

## Usage
```bash
npm run start
```
